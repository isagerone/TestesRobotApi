# Projeto de Testes Automatizados com Robot Framework

Este projeto é um exemplo de automação de testes para APIs, utilizando o Robot Framework. Ele cobre requisições HTTP básicas, como GET, POST, PUT e DELETE, para validar o funcionamento de endpoints de uma API.

## Pré-requisitos

Antes de executar os testes, certifique-se de ter instalado:

- Python 3.x
- Robot Framework
- Bibliotecas necessárias
